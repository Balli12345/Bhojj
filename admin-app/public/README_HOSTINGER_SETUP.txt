HOW TO DEPLOY ON HOSTINGER (5 EASY STEPS):
------------------------------------------------------------------------
1. Login to your Hostinger hPanel dashboard (https://hpanel.hostinger.com)
2. Go to "Websites" -> Click "Manage" next to your domain.
3. In the sidebar, open "Files" -> "File Manager" -> Click "Go to File Manager".
4. Navigate inside the "public_html" directory.
   - If there is a default file like "default.php", you can delete or rename it.
5. Upload this zip file (bhojj-hostinger-deployment.zip) directly into "public_html".
6. Right-click the zip file in File Manager -> Click "Extract" -> Extract here.
7. Verify that:
   - index.html is directly in public_html/
   - .htaccess is directly in public_html/ (ensure "Show Hidden Files" is ON)
   - assets/ folder is in public_html/
8. Done! Visit your domain (e.g. https://yourdomain.com) and test all portals:
   - Customer Portal
   - Restaurant Partner Portal
   - Delivery Partner Fleet Portal
   - Super Admin Master Control

HOSTINGER SSL & HTTPS:
------------------------------------------------------------------------
In Hostinger hPanel -> Security -> SSL -> Click "Install SSL" (Lifetime Free).
Toggle "Force HTTPS" ON for secure padlock.
