# BHOJJ Customer Native Android App

Package ID: com.bhojj.customer

Separate Capacitor Android project using the existing BHOJJ web UI as bundled content. The Customer build uses the mobile-responsive Customer source while preserving the original Customer visual design.

Build: npm install -> npm run android:sync -> npm run android:build
Open Android Studio: npx cap open android

This is native Android project source (Capacitor hybrid), not a prebuilt APK/AAB.
